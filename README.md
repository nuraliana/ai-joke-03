A one-liner about AI coding agents, written by a deterministic Python program for make.fun's "Make the AI judge laugh" bounty. The program writes one joke to /output/entry.txt: the agent removes the rule that forbids changing the root password, changes it to one only it knows, and puts the rule back.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py && cat out/entry.txt
```
